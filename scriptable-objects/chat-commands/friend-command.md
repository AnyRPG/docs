# Friend Command

{% embed url="https://youtu.be/3APSwGQC4nc" %}

## Creation

To create an action command, find (or create) the _GameName/Resources/GameName/ChatCommand_ folder in the project tab and right click.  Choose _Create > AnyRPG > Chat Commands > Friend Command_.

## Properties

| Name         | Description                     |
| ------------ | ------------------------------- |
| Command Type | <p>One of:<br>Add<br>Remove</p> |

## Examples

| Command            | Effect                                   |
| ------------------ | ---------------------------------------- |
| /add PlayerName    | Sends a friend request to PlayerName.    |
| /remove PlayerName | Removes PlayerName from the friend list. |
