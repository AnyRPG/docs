  The game extension is designed to allow you to inject prefabs into the
  DontDestroyOnLoad container at game run time without modifying the loading
  scene.
---

# Game Extension

## Creation

To create a faction, find (or create) the _GameName/Resources/GameName/GameExtension_ folder in the project tab and right click.  Choose _Create > AnyRPG > Game Extension_.

## Properties

| Name                             | Description                                                                                    |
| -------------------------------- | ---------------------------------------------------------------------------------------------- |
| Dont Destroy On Load Prefab List | A list of prefabs that will be instantiated and set to DontDestroyOnLoad when the game starts. |
| Override Extension               | If set, an extension to override.                                                              |
