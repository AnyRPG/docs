# Guildmaster Config

## Creation

To create a guildmaster config, find (or create) the _GameName/Resources/GameName/InteractableOptionConfig_ folder in the project tab and right click.  Choose _Create > AnyRPG > Interactable > Guildmaster Config_.

## Properties

A guildmaster config does not have any properties other than the properties shared by all [Interactable Option Configs](./#properties).

## Next Steps

* Add a guildmaster config to a [Unit Profile](../unit-profile.md) to allow the character to serve as a guildmaster.
