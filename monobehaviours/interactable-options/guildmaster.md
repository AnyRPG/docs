# Guildmaster

## Properties

A Guildmaster does not have any properties other than the properties shared by all [Interactable Option Configs](../../scriptable-objects/interactable-option-configurations/#properties).

## Dependencies

* An Interactable Monobehavior must be on the same GameObject.
